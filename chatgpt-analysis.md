## Preliminary recommendation

Having also inspected several individual Markdown files, I recommend adopting this consistent sequence:

For each case file:

1. Case identification and archival citation
2. Historical overview and principal participants
3. Chronology, where useful
4. Designatio Actorum, with transcription, translation, and document links
5. Individual documents in archival order

For each individual document:

1. Document title, number, and date
2. Brief overview of its contents
3. Historical or administrative explanations, where warranted
4. Original document images
5. German transliteration
6. English translation
7. Additional interpretive notes, if needed
